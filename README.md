# Sistema de Aluno - Java | Projeto Acadêmico USCS

Projeto em Java para cadastro e avaliação de alunos.

### O que foi feito
- Classe `Aluno` com atributos: nome, codmat, cpf, sexo, nota_P1, nota_P2, nota_P3
- Método `imprimi_sexo()` - verifica sexo com if/else
- Método `media_Aluno()` - calcula média das 3 provas: (P1+P2+P3)/3
- Método `Resultado()` - retorna Aprovado se média >= 6, senão Reprovado

### Tecnologias
Java, NetBeans, POO
